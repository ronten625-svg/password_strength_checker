# Password Strength Checker

A Python program that checks whether a password meets
strength requirements.

## Rules
- At least 6 characters
- At least one uppercase letter, one lowercase letter,
  one digit and one special character
- No spaces
- No repeated characters in a row
- No sequential characters (e.g. abc, 123)

## Usage
```
python strong_password.py
```
Enter a password when prompted. The program keeps asking
until the password is strong
